Inspired by the popular 8-bit 2d game, Tapper, Tapped Out is a reverse engineered project of mine to help explore basic core concepts for level creation, possible end-game outcomes, and difficulty scaling.
Completion of each tutorial, helps scale the player's difficulty setting by continuing to teach them the principles of how to play the game, but to also demonstrate the changes that will follow as progression ensues.
Possible game fail states include too many broken bottles, whether it's the player overserving at a bar or failing to catch 'empty' beers on the return from customers, and if a 'customer' reaches the end of the bar,
time to serve is set to zero and game ends with player being transported to the bar where they couldn't keep up.

Working on recreating an arcade game based on serving drinks to clients on different schedules and tiers based on level
